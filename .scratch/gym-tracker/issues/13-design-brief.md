# 13: Write the Claude Design brief

**What to build:** A design brief the user can paste into Claude Design to design the app's look. It describes the app's purpose and context: used one-handed at the gym, between sets, often with sweaty hands, mostly glanced at. It then covers every screen from the spec (home, session, end-of-session summary, overview, exercise page, history and session detail, settings, first-run setup, and the stale-session prompt). For each screen it lists the content, the actions and their importance, and the main states (for example a bodyweight exercise, the last exercise left, a below-range result). It includes realistic sample data and says what to hand back: preferably a link to the design or exported code, otherwise screenshots of every screen.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] The brief is saved under this feature's `.scratch` folder as a markdown document
- [ ] It covers every screen and state listed above, with realistic sample data

- [ ] It says what to hand back and in what form
- [ ] The user has read it and confirmed it's ready to take to Claude Design
